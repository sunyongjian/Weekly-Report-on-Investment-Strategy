# 第 2 期 · 2026-10-10｜大厂砸钱搞 AI：先看现金流去了哪，再看谁在下注

**本期主线：** 三个人看同一件事——科技巨头把赚来的现金大把投进 AI。Damodaran 说先看现金流被吃掉多少，段永平说不投会掉队，Burry 说这是抢寡头地位、很多会变沉没成本。三人对「钱花了」没分歧，分歧在「这些钱能不能赚回来」，而这一点现在谁也证明不了。

收集范围：10 月 3 日–10 月 10 日。Damodaran 博客、Burry 的 X 和 Substack、段永平雪球问答有实质内容；Ackman 和 Gerstner 这周在 X 上基本是政治和公益帖，没收；本期没找到讲黄金框架、够格的新长文；Reddit 本期未能访问（浏览器拦截该站）；Marks 和巴菲特没有新文本。

### ① Damodaran：AI 投入先吃掉现金流，后才进利润——别等会计减值再反应

| 项 | 内容 |
| --- | --- |
| 跟你的关系 | 纳指 / 美股科技估值。你的 QDII 基金重仓的正是这批「造 AI 的人」。 |
| 谁在说 | Aswath Damodaran，纽约大学商学院教授，专教估值。不管外部资金，没有可查的基金业绩；他自己说大部分仓位在指数基金，持有七巨头里的 5 家（不含特斯拉、英伟达），新钱多放在约 4% 的短期美债里。 |
| 他图什么 | 教学和声誉为主，卖书和网课但不荐股。持有 5 家巨头，所以对「AI 赢」有切身利益，但他也公开说自己没押满。 |
| 逻辑链 | 巨头的 AI 资本开支（买机器、建机房的钱）在算自由现金流时当期全扣，在利润表里却按折旧慢慢摊 → 所以利润看着涨得猛（美股 2026 年二季度净利润同比 +57%），现金流却被挤 → 证据：标普 500 把盈利的 63% 还给股东，2004 年以来最低；科技行业负债一年 +18.8% → 结局三种：AI 回报高于资金成本；部分回报不够；大额减值 → **最弱一环：他判断「市场会先于会计反应」，这是经验猜测，没有给出可检验的时点** → 结论：不存在「先不表态」这个选项，不买 AI 也是一种押注。 |
| 什么情况下它是错的 | ① 未来 4–6 个季度，巨头自由现金流和回购开始回升，而资本开支增速放缓——说明投入期过去了；② 巨头把折旧年限再拉长，利润好看但现金流继续变差——说明他担心的会计滞后正在发生。看财报里「经营现金流 − 资本开支」这一行就够了。 |
| 对谁成立 / 对谁不成立 | 成立：持有纳指、靠利润增长给估值的人——要知道利润里有多少是折旧摊得慢撑出来的。不成立：只看营收增长或产品热度的人，这套框架帮不上。 |

### ② Burry：垄断者本不必拼命花钱，它们在抢 AI 寡头地位；很多钱会变成沉没成本

| 项 | 内容 |
| --- | --- |
| 跟你的关系 | 纳指 / 美股科技。和 ① 看的是同一笔钱，结论相反。 |
| 谁在说 | Michael Burry，《大空头》原型，2008 年做空次贷出名。他的 Scion 基金 2025 年披露过英伟达、Palantir（美国一家做数据分析软件的公司）的看跌期权，之后注销基金、改写付费 Substack。近年的整体业绩查不到经审计的数。 |
| 他图什么 | 付费订阅收入——「泡沫要破」的叙事越有人信，订阅越多；他公开挂过 AI 空单，立场和仓位是一致的。这篇主体在付费墙后，本期只拆得到公开部分。 |
| 逻辑链 | 微软、亚马逊、谷歌、Meta 在各自领域已经垄断 → 垄断者不该像「不花就会死」那样花钱 → 所以它们花钱不是为了活，是为了把 AI 变成又一笔垄断租金；OpenAI、Oracle 花钱是为了挤进寡头圈 → 这笔支出「没有明确的经济终点」 → **最弱一环：「压缩会发挥作用」（模型越来越省算力）所以大量投入会变沉没成本——公开部分只有断言，没有数字** → 另一条线：数据中心靠私募股权、私募信贷、保险公司资金撑着，这些地方的估值已在松动，长期利率又在涨 → 再加市场宽度：他拿 2000 年初类比——当时 70–80% 的股票已经在燊市，指数还在创新高，他叫这「否认」。 |
| 什么情况下它是错的 | ① 云业务（微软 Azure、亚马逊 AWS、谷歌云）收入增速持续高于资本开支增速；② 私募信贷没有出现成规模的违约或赎回限制；③ 上涨公司的比例扩大。三条都能在季报和新闻里看到。 |
| 对谁成立 / 对谁不成立 | 成立：用「投入有没有终点」来检查一家公司花钱的人——这个问题对阿里、腾讯同样适用。不成立：定投、持有十年的人：Burry 讲的是波动和时点，他自己做空 AI 也曾被行情压过。 |
| 原文 | [Short Thoughts: The AI Cloud Oligopoly（10 月 8 日，主体付费）](https://michaeljburry.substack.com/p/short-thoughts-the-ai-cloud-oligopoly) |

### ③ 段永平：大厂收入没变差，只是在为未来投资；投 AI 是「囚徒困境」，不投会掉队

| 项 | 内容 |
| --- | --- |
| 跟你的关系 | 港股中概科技 + 纳指。提问的人问的就是阿里、腾讯这类「互联网大厂」：投入越来越重、自由现金流变差，商业模式是不是在变差。 |
| 谁在说 | 段永平，步步高创始人，雪球 ID「大道无形我有型」。公开谈过的仓位有苹果、腾讯、茅台等；没有经审计的公开业绩。 |
| 他图什么 | 不募资、不卖课。但他持有苹果、腾讯这类公司，「AI 投入是必要的」对他的持仓是好话。另外是一句话的随手回复，不是长文。 |
| 逻辑链 | 大厂收入没变差 → 现金流变差是因为在投未来 → AI 投入像囚徒困境（博弈论里的情形：大家都不投最好，但只要别人投，你不投就最惨，所以人人都投）→ 不投的大概率掉队 → **最弱一环：囚徒困境只说明「不得不投」，没说明「投了能赚回来」。如果人人都投，结果可能是大家都变成重资产、回报率都下降——这正是提问者担心的** → 所以他的回答其实是在说「这是竞争下的必然」，而不是「商业模式没变差」。 |
| 什么情况下它是错的 | 看两个数：① 大厂的云和 AI 收入增长，能不能追上资本开支增长；② 「利润 ÷ 投进去的资本」这个回报率在 2–3 年里是稳住还是一路下滑。一路下滑，就是「商业模式在变差」。 |
| 对谁成立 / 对谁不成立 | 成立：相信头部大厂竞争地位、愿意等投入期过去的长期持有者。不成立：用自由现金流或分红回购给估值的人——对他们来说，现金流变差就是估值变低，不管原因是什么。 |

### ④ 段永平：买拼多多还是买纳指 ETF？「看懂指数对我而言是更难的」

| 项 | 内容 |
| --- | --- |
| 跟你的关系 | 中概科技 + 纳指，正好是你两类持仓的选择题。PDD＝拼多多和 Temu 的母公司，在美股上市；QQQ＝跟踪纳斯达克 100 指数的 ETF。 |
| 谁在说 | 段永平，同上。 |
| 他图什么 | 拼多多创始人黄铮年轻时受过他提携，他也曾公开说过持有拼多多——谈 PDD 时他不是中立的人。不过这次他没荐股，只反问了提问者。 |
| 逻辑链 | 提问者 2021 年买港美股几乎全亏，现在在 PDD 和 QQQ 间纠结，理由是「PDD 利润好但上市以来股价年化不好」→ 段反问：「你是想买过去涨得很好的公司？」→ 即：过去的股价涨幅不是买入理由，要看的是未来的生意 → 另一人问「看不懂时买宽基指数是否最优」，他答「看懂指数对我而言是更难的」→ 意思是：指数是一篮子公司，他只看得懂少数几家 → **最弱一环：这对「能看懂生意的人」成立；对大多数人，买指数恰恰是因为不需要看懂每一家，他没回答「看不懂的人该怎么办」** |
| 什么情况下它是错的 | 自测：你能不能用三句话讲清「这家公司 5 年后靠什么赚钱、赚多少、什么会让它赚不到」。讲不清，对你来说指数反而是更容易的选择——他的话对你就不成立。 |
| 对谁成立 / 对谁不成立 | 成立：愿意花时间研究少数公司、能承受集中持仓波动的人。不成立：要的是分散、省时间的人。注意 ① 里的 Damodaran 正好是反例：教了一辈子估值，大部分钱却放在指数里。 |

**分歧在哪一层**

| 话题 | 一派怎么说 | 另一派怎么说 | 分歧在事实 / 推理 / 价值观 |
| --- | --- | --- | --- |
| 巨头 AI 投入值不值 | 段永平：竞争下不得不投，收入没变差 | Burry：垄断者本不必投，是在抢寡头租金，大量会变沉没成本 | 事实：AI 投入的回报率现在没人算得出；Damodaran 把它列成三种结局，不假装知道 |
| 「只有少数股票在涨」说明什么 | Damodaran：利润增长集中在科技等少数行业，过半公司净利润下降，指数涨是有利润撑的 | Burry：和 2000 年初一样，是燊市前的「否认」信号 | 推理：同一个宽度事实，一个用利润解释，一个用历史类比解释 |
| 看不懂时该买什么 | 段永平：看懂指数更难，只买懂的几家 | Damodaran：大部分仓位放指数，接受市场共识 | 价值观：更在意「买自己懂的」还是「不押错」，也取决于你有多少时间研究 |

**本期沉淀**

1. 不是「利润涨了，公司就更值钱」，是「先看利润里有多少变成了能拿回来的现金」。重投入期的公司，利润和自由现金流会分叉。
2. 不是「大家都在投，所以投对了」，是「不得不投」和「投了能赚回来」是两个问题，要分开验证。
