### ② Damodaran：总估值算对了，也可能因为股数口径错了，高估你分到的那一份

| 项 | 内容 |
| --- | --- |
| 跟你的关系 | 纳指科技与港股科技的通用估值方法。Anthropic＝开发 Claude AI 模型和服务的公司，这里仅作股权结构案例，不代表你的基金一定持有。 |
| 谁在说 | Aswath Damodaran，纽约大学金融学教授，公开发布估值方法与模型。本次未找到经审计的完整个人投资业绩；这篇不是基金业绩报告。 |
| 他图什么 | 直接可见的是估值教学、著作与专业声誉。他也在修订自己此前的 Anthropic 模型，天然有维护方法一致性的动力；本文未明确披露该公司的实际仓位。 |
| 逻辑链 | 员工期权、限制性股票与可转债，都可能分享股东权益 → 只除以普通流通股，容易漏掉其他权利；把所有期权直接算成股数，又可能忽略行权时公司收到的钱 → 他主张先估已有期权的价值并从股权总价值中扣除，再按普通股与相关限制性股票分配。期权＝以约定条件购股的权利；限制性股票＝通常附服务或归属条件的股份。**最弱一环：期权的存续、行权与归属假设仍可能估错，精细公式不能替代条款核对。** |
| 什么情况下它是错的 | 若期权已取消、实际归属数量或转换条款改变，就要重算。若只是总股数数字相近，不能据此判断各种方法等价；还要核对是否已在分子扣过同一批权利，避免分母再计一次。 |
| 对谁成立 / 对谁不成立 | 适合比较不同平台的市值、市盈率和每股利润。算例：总权益价值不变，享有同等权利的股份多 20%，每股分到的价值就约少 16.7%。这是机制算例，不是任何公司的目标价；有特殊投票权或现金分配权时，也不能简单视为等份。 |
| 原文 | [The Rocky Road from Aggregate to Per Share Value，11 月 18 日](https://aswathdamodaran.blogspot.com/2026/11/the-rocky-road-from-aggregate-to-per.html) |

### ③ Damodaran：关键人物的价值，要用“有他”和“没他”的两套经营假设来算

| 项 | 内容 |
| --- | --- |
| 跟你的关系 | 纳指科技，也适用于评价港股公司的创始人与接班安排。英伟达＝设计 AI 计算芯片并提供配套软件的公司。这里只取文中的关键人物估值方法，不把相关事件细节作为本期判断依据。 |
| 谁在说 | 同为 Damodaran。这篇把管理层作用拆回经营变量，并提供情景模型；个人完整历史投资表现本次仍未查得。 |
| 他图什么 | 延续其“故事必须对应数字”的教学框架。文末还表达了附条件重新持有英伟达的意向，因此并非完全没有个人投资立场；意向不等于已成交持仓。 |
| 逻辑链 | 领导者可能影响产品方向、客户关系、人才和资本配置 → 分别估公司在关键人物在任与离开情况下的现金流和风险 → 两者价值差才是人物贡献，不能把历史成就全部当作未来不可替代性。**最弱一环：“没他”的世界不可直接观察，若把增长、利润率和风险全部同时往坏处改，可能重复惩罚同一项担忧。** |
| 什么情况下它是错的 | 若后续 2–4 个季度，接班团队保持产品交付、客户续约和关键人才稳定，悲观的人员依赖假设就应缩小；反过来，若关键岗位持续流失、交付推迟且客户转向替代品，认为组织已能脱离创始人的假设就被削弱。 |
| 对谁成立 / 对谁不成立 | 适合审查“相信管理层”到底意味着什么：列出最依赖个人的两三项工作，以及谁能接手。不适合按人物名气统一加减一个折价；很能干与权力不受约束，也可以同时存在。 |
| 原文 | [The Cost of Human Frailty，11 月 19 日](https://aswathdamodaran.blogspot.com/2026/11/the-cost-of-human-frailty-nvidias.html) |

**分歧在哪一层**

| 话题 | 一派怎么说 | 另一派怎么说 | 分歧在事实 / 推理 / 价值观 |
| --- | --- | --- | --- |
| 腾讯的投入阶段 | 原文认为新业务进展和未来投入回落，支持把利润压力看作过渡 | 评论区反方更重视眼前融资负担，追问新收入何时覆盖投入 | 推理与时间：收入增长是否足够，融资能否撑到回报兑现；双方转述数字仍需回公司披露核对 |
| 每股价值怎么分 | 只看普通股，或把全部潜在股份一并加入分母 | Damodaran 主张单独估期权权利，再计算剩余权益 | 事实与计算口径：谁有权分、何时能分、行权会不会带来现金 |
| 相信创始人意味着什么 | 常见人物叙事把过往成功延伸成未来不可替代 | 本期第三条要求评估接班者、团队与具体经营变量 | 推理：第三条是对这种叙事的检验，不是本期另有一位作者给出的相反结论 |

**本期沉淀**

- 不是解释了费用为何增加，就是证明了投入能回本。
- 不是公司整体变好了，就是你的每一股能分到更多。
