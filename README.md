# 投资策略与理念周报

## 怎么读

每周三、周六各一期，每期只回答一个问题：**这一期看到的观点里，哪几个逻辑站得住，说话的人又图什么。** 不数谁看多谁看空，只拆观点。

| 每期固定部分 | 讲什么 |
| --- | --- |
| 本期主线 | 一句话：这期所有观点合起来说明了什么 |
| 观点拆解（3–5 条） | 每条拆成：观点一句话、谁在说、他图什么、逻辑链和最弱的一环、什么情况下它是错的、对谁成立 |
| 分歧在哪一层 | 同一话题各派观点放一起，看分歧是在事实、推理还是价值观上 |
| 经典文本更新 | Howard Marks 出了新备忘录、巴菲特出了新股东信时才写，没有就跳过 |
| 本期沉淀 | 1–2 条可以带走的原则，句式是「不是 X，是 Y」 |

**不做的事：** 不报行情（行情在每天 10:30 的日报里），不给买卖建议，不把任何人的观点当结论。新出现的术语会附上大白话解释。

## 固定信源

选人标准不是「跟着能赚钱」，而是**有真金白银或能查的记录、公开拆逻辑、会认错**。一项对 2.9 万多个荐股博主的研究发现，56% 是反向指标，而且粉丝越多水平越差（[来源](https://sherwood.news/markets/your-favorite-social-media-guru-is-probably-a-bad-stock-picker-study-shows/)）。

| 信源 | 在哪 | 看什么 | 他图什么（要当心） |
| --- | --- | --- | --- |
| 段永平（大道无形我有型） | 雪球 | 长期公开问答、买股票就是买公司的思路 | 有真仓位，提到的公司多是自己持有的 |
| Aswath Damodaran | X @AswathDamodaran、[博客](https://aswathdamodaran.blogspot.com) | 完整估值表格和推理过程，最适合学方法 | 不管钱、不荐股，是纯教学 |
| Bill Ackman | X @BillAckman | 用真仓位写长文论证集中持仓 | 谈的基本是自己的持仓；政治类发言要分开看 |
| Brad Gerstner | X @altcap | AI 和科技巨头的产业逻辑 | 看好的多是自己投过的公司 |
| Michael Burry | X、Substack | 逆向和做空思路 | 常删帖，看到时往往已过时；现在写付费 Substack |
| Cathie Wood / Chamath | X | 反面教材，练「拆动机」 | 收入和影响力来自你相信这个叙事 |
| Howard Marks 备忘录 | [Oaktree](https://www.oaktreecapital.com/insights/memos) | 市场周期、风险、投资者心理；不定期发布 | 他管理的如果是信贷基金，观点会偏向这一块 |
| 巴菲特股东信 | [伯克希尔](https://www.berkshirehathaway.com/letters/letters.html) | 资本配置、认错、长期主义；每年 2 月底 | 写给自己的股东，整体基调正面 |
| 公开讨论区 | Reddit r/SecurityAnalysis、r/ValueInvesting；Seeking Alpha 公开文章 | 补充分歧视角 | 匿名，身份和持仓多半查不到 |

要调整信源，直接改这张表就行；定时任务每次运行前都会先读它。
